# Recursos originales

El tablero se dibuja con Graphics de Phaser. Los iconos SVG y la composición de flechas de portada se crean en el código del proyecto. Los sonidos se sintetizan con Web Audio. No se descargan fuentes, imágenes ni audio de terceros en tiempo de ejecución.

Este directorio está reservado para futuros recursos originales. Sus archivos de autor deben versionarse; las compilaciones y cachés deben permanecer ignoradas.
