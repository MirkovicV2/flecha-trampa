# FLECHA TRAMPA

Juego móvil de puzles de flechas. TypeScript estricto, Phaser 3, Vite y Capacitor.

Proyecto en desarrollo. Node.js 24 y Git son necesarios. En Windows, `powershell -ExecutionPolicy Bypass -File scripts/dev.ps1` usa la instalación portátil local si existe.

```sh
npm ci
npm run dev
npm run check
```

El desarrollo se integra en `develop` desde ramas `feature/*`. `main` recibe únicamente versiones verificadas. Se utiliza Conventional Commits y nunca force push.
